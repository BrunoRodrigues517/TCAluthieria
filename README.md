# TCAluthieria

O TCAluthieria é um site para a Luthieria Rodrigues(Luthieria não oficial criada por mim para apenas ter um nome) criado como projeto de conclusão de ano para a disciplina de Banco de Dados. A ideia é facilitar a venda de instrumentos e o acompanhamento dos serviços de conserto.

## O que dá para fazer

**Clientes** podem criar uma conta, entrar no site, ver os instrumentos à venda, escolher a forma de pagamento e finalizar uma compra. Também podem avaliar os instrumentos com uma nota de 0 a 10 e acompanhar o conserto dos próprios instrumentos.

**Gerentes** podem consultar e pesquisar o estoque, adicionar instrumentos e tipos ao catálogo, acompanhar os instrumentos enviados para conserto, atualizar o estado do reparo e registrar as devoluções. O site também mostra um resumo dos valores recebidos e o histórico de compras e entregas.

## Tecnologias

O projeto foi feito com HTML, CSS e JavaScript. Os dados são armazenados em um banco PostgreSQL acessado pelo Supabase.
